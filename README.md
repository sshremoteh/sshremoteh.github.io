# NOVA MUSIC (v1.0)

**NOVA MUSIC** — музыкальный веб-плеер в стиле **YouTube Music TV**, специально спроектированный для умных телевизоров **LG Smart TV с webOS 2.0** (движок **WebKit 538.2**), управления с телевизионного пульта ДУ и запуска через **Media Station X (MSX)** либо встроенный браузер.

## 📺 Инструкция по подключению на LG webOS 2.0

### Способ 1: Запуск через Media Station X (Рекомендуемый)
1. Установите приложение **Media Station X** из официального магазина **LG Content Store** на телевизоре.
2. Запустите **Media Station X**.
3. Перейдите в меню: **Settings** (шестерёнка в правом верхнем углу) → **Start Parameter** → **Setup**.
4. В поле ввода укажите адрес:
   ```text
   sshremoteh.github.io/nova-music
   ```
5. Включите переключатель безопасности (Security / SSL Lock), подтвердите ввод (кнопка с галочкой).
6. Перезапустите приложение Media Station X (или нажмите OK при запросе перезагрузки).
7. На экране появится меню с плиткой **«Open NOVA MUSIC»**. При нажатии плеер откроется в полноэкранном режиме с готовой навигацией.

### Способ 2: Запуск через штатный браузер LG webOS 2.0
1. Откройте приложение **Веб-браузер** (Web Browser) на телевизоре.
2. В адресной строке введите:
   ```text
   https://sshremoteh.github.io/nova-music/
   ```
3. Нажмите кнопку **Enter** / **Перейти**.
4. Для удобства добавьте страницу в закладки телевизора.

## 🎮 Управление с телевизионного пульта (D-Pad & Magic Remote)

| Кнопка пульта | Действие в NOVA MUSIC |
| :--- | :--- |
| **Стрелки (Вверх / Вниз / Влево / Вправо)** | Перемещение фокуса между элементами интерфейса |
| **Влево из контента** | Быстрый переход в боковое меню (Sidebar) |
| **Вправо из меню** | Возврат к последней активной карточке / строке контента |
| **Вниз из контента** | Переход к мини-плееру в нижней части экрана |
| **OK / Enter** | Воспроизведение трека, открытие альбома, нажатие кнопки |
| **BACK / Возврат / Esc (код 461 / 10009 / 8 / 27)** | Закрытие модального окна &rarr; возврат из полноэкранного плеера &rarr; переход в меню &rarr; выход |
| **Play / Pause (179, 415, 19)** | Пауза / Возобновление воспроизведения |
| **Next / Fast Forward (417, 473)** | Следующий трек / перемотка вперёд |
| **Prev / Rewind (412, 472)** | Предыдущий трек / перезапуск трека / перемотка назад |
| **Stop (413)** | Остановка воспроизведения |
| **Указатель LG Magic Remote** | Наведение курсора подсвечивает элемент фокусом, клик активирует действие |

## 🚀 Реализованный функционал

1. **Дизайн в стиле YouTube Music TV:**
   * Тёмная палитра (`#0F0F0F`, `#181818`, `#202020`) с акцентом `#FF0033`.
   * Адаптивность под разрешения **1920x1080** и **1280x720**.
   * Высококонтрастные состояния фокуса с красным контуром и эффектом масштабирования (`scale(1.05)`).
   * Чёткие SVG-обложки без пикселизации.

2. **Главные экраны:**
   * **HOME:** Недавно добавленные треки, карусель альбомов, полный список песен.
   * **SEARCH:** Мгновенный локальный поиск по названию, артисту и альбому с экранной QWERTY-клавиатурой для пульта.
   * **LIBRARY:** Вкладки «Все треки», «Избранное», «Альбомы» и «Исполнители».
   * **PLAYLISTS:** Создание пользовательских плейлистов, добавление и удаление треков, воспроизведение плейлиста целиком.
   * **NOW PLAYING:** Полноэкранный режим с большой обложкой, таймлайном, регулировкой очереди, перемешиванием (Shuffle) и повтором (Repeat All / Repeat One).
   * **REPOSITORIES:** Управление источниками музыки по URL.

3. **Аудио-движок:**
   * Единый экземпляр `HTML5 Audio` (`var audio = new Audio()`).
   * Воспроизведение, пауза, перемотка (seek), громкость, переключение треков.
   * Очередь (Queue), автопереход на следующий трек (`ended`), зацикливание (`repeatMode`).
   * Корректная обработка ограничений Autoplay без падений.
   * Информативные сообщения об ошибках сети и декодирования.

4. **Система внешних музыкальных репозиториев:**
   * Подключение репозиториев по URL.
   * Валидация структуры JSON и обязательных полей.
   * Разрешение относительных путей аудиофайлов и обложек относительно `tracks.json` и `repository.json`.
   * Дедупликация треков.
   * Отображение источника каждого трека.

5. **Локальное хранилище данных:**
   * Безопасная обёртка над `localStorage` с автоматическим fallback на память в случае ошибок или приватного режима.
   * Сохранение подключённых репозиториев, избранного, плейлистов, последнего трека и настроек воспроизведения.

## 🛠 Структура музыкального репозитория

Вы можете опубликовать собственный музыкальный каталог на любом веб-сервере с поддержкой HTTPS и CORS (например, GitHub Pages).

### 1. Файл `repository.json`
```json
{
  "name": "My Music Catalog",
  "id": "my-music-catalog",
  "version": 1,
  "description": "Custom music collection",
  "tracks": "tracks.json"
}
```

### 2. Файл `tracks.json`
```json
{
  "tracks": [
    {
      "id": "track_001",
      "title": "Song Title",
      "artist": "Artist Name",
      "album": "Album Name",
      "cover": "covers/cover1.jpg",
      "audio": "audio/song1.mp3",
      "format": "mp3",
      "duration": 180
    }
  ]
}
```
*Пути к аудио и обложкам могут быть как абсолютными (`https://...`), так и относительными.*

## ⚙️ Технические особенности для старого WebKit 538.2

* **Strict ES5:** Код написан без `let`, `const`, стрелочных функций, шаблонных строк, `async/await`, классов и деструктуризации. Проверен парсером `acorn` с ключом `{ ecmaVersion: 5 }`.
* **CSS без Custom Properties:** В стилях намеренно не используются CSS-переменные (`var(--...)`), так как движок Safari/WebKit 538.2 их не поддерживает.
* **Flexbox/Block вместо CSS Grid:** Вёрстка выполнена на базе блочной модели, табличных дисплеев и flexbox с префиксами `-webkit-`, что исключает поломку макета на старых телевизорах.
* **Отсутствие тяжелых библиотек:** Чистый Vanilla JavaScript, нулевые накладные расходы на процессор и память ТВ.

## 📋 Чек-лист проверки на физическом LG Smart TV webOS 2.0

Поскольку физическое устройство находится на стороне пользователя, рекомендуется провести следующие приёмочные тесты на реальном телевизоре:
1. Запуск через MSX: ввод параметра `sshremoteh.github.io/nova-music`, загрузка плитки меню и переход в плеер.
2. Проверка видимости фокуса: навигация стрелками пульта по меню и карточкам, чёткость красной рамки с расстояния 3 метров.
3. Воспроизведение демо-трека: нажатие OK на треке "Midnight Starlight", появление звука из динамиков ТВ.
4. Проверка фонового воспроизведения: переход в раздел Search во время проигрывания музыки (звук не должен прерываться, мини-плеер внизу должен показывать прогресс).
5. Проверка кнопки Back на пульте: возврат из полноэкранного плеера в каталог.
